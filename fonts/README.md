# Dołączone czcionki

Pliki w tym katalogu są używane przez `scripts/generate.py`, żeby generowanie
karuzeli działało bez dostępu do internetu i niezależnie od czcionek
zainstalowanych w systemie.

- **Liberation Sans / Serif / Mono** — metrycznie zgodne odpowiedniki
  Arial, Times New Roman i Courier New. Licencja: SIL Open Font License 1.1.
- **DejaVu Sans** — licencja Bitstream Vera / DejaVu (dozwolona redystrybucja).

Obie rodziny są wolnymi fontami z pełnym prawem do redystrybucji.
